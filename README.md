

# Customer Churn Analysis

## Project Overview
This project focuses on analysing customer churn data to understand customer behaviour, identify churn patterns, and explore factors associated with customer retention.

## Technologies Used
- Python
- Pandas
- NumPy
- SQL
- Matplotlib

## Project Workflow
1. Import customer dataset.
2. Clean and preprocess data using Pandas.
3. Perform exploratory data analysis.
4. Analyse customer information using Python and SQL.
5. Identify patterns and factors associated with customer churn.
6. Visualize findings and summarize insights.

## Project Objectives
- Understand customer churn patterns.
- Analyse customer behaviour.
- Explore customer retention trends.
- Identify factors associated with customer attrition.
- Support data-driven business decisions.
